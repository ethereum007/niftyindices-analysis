Sources, methodology and update status

Source. NSE Indices daily reports. Source CSV files are archived with SHA-256 checksums. This is end-of-day snapshot data, not a live feed. Coverage is the number of indices in the selected source file, not the complete NSE index catalogue.

Returns. 1M, 3M and 1Y use 30, 90 and 365 calendar days. The baseline is the last stored observation on or before the target, within 7 days. Missing history stays unavailable. Exact baseline dates appear in index details and exports. Standard indices show price-level changes; total-return, currency, inverse, leveraged, volatility and fixed-income variants are separated. No TRI-adjusted equity comparison is implied.

Grouping. Broad-market and sector groups use curated index-name lists for navigation. The special-variant filter uses name rules. These are local research groups, not an authoritative NSE classification. Cross-index valuation comparisons are descriptive, not buy/sell signals. Watchlists are stored only in this browser.

Updates. Your local Windows task downloads and rebuilds this dashboard at 19:00 and 21:00 IST weekdays while the PC is on and you are logged in. A hosted copy is a publication snapshot; it is not connected to the local scheduler. There is no cloud data-refresh connection yet. The date at the top always identifies the selected data.
