Sources, methodology and update status

Source. NSE Indices daily reports. Source CSV files are archived with SHA-256 checksums. This is end-of-day snapshot data, not a live feed. Coverage is the number of indices in the selected source file, not the complete NSE index catalogue.

Returns. MTD begins at the previous month-end. 1M, 3M, 6M, 1Y, 2Y, 3Y and 5Y use calendar-month/year anniversaries (month-end clamped). The baseline is the last stored observation on or before the target, within 7 days. Missing history stays unavailable. Exact baseline dates appear in index details and exports. Cumulative return is end/start minus one. CAGR for 1Y and longer is (end/start)^(365.2425/actual elapsed days) minus one. Charts always show cumulative rebased levels, even when the ranking table shows CAGR. Standard indices show price-level changes; total-return, currency, inverse, leveraged, volatility and fixed-income variants are separated. No TRI-adjusted equity comparison is implied.

Grouping. The sector filter matches the 34 entries on the official sectoral index catalogue as checked on 20 October 2026, including MidSmall and Healthcare variants. Other groups use curated names for navigation. The special-variant filter uses name rules. These local navigation mappings do not replace the official catalogue; snapshot membership and naming can vary over time. Equity is the default view. Debt and other instruments have separate universes and snapshot dates; All assets is available explicitly. Constituents show current published membership with retrieval provenance, not historical membership. Stock changes use the dated official NSE closing-price file, and are not weighted contributions to the index. Cross-index valuation comparisons are descriptive, not buy/sell signals. Watchlists are stored only in this browser.

Updates. Your local Windows task downloads and rebuilds this dashboard at 19:00 and 21:00 IST weekdays while the PC is on and you are logged in. A hosted copy is a publication snapshot; it is not connected to the local scheduler. There is no cloud data-refresh connection yet. The date at the top always identifies the selected data.
